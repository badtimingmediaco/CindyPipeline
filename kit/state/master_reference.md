## 2 · BRAND ASSETS & RULES

### Fonts (exactly three)

| **Awelier** | Sub-labels, small italic lead-ins ("how to", "how to turn"), emphasis words |

### Title format (learned from her actual reels)
- **Line 1:** small lowercase Awelier italic lead-in ("how to", "how to turn", "I let")
- **Line 2:** massive Markerist bold — the main subject
- **Line 3:** continuation or secondary line
- **Orange (#E8663D) accent** goes on: Claude, a tool name, or THE single emotional/outcome word (SECRET, unrejectable, LYING, $30K) — never on filler words
- **Black stamp boxes** for numbers ("5", "4", "3")
- **Pill/badge shapes** for tool/category labels (like "Opus / Sonnet / Haiku")
- **Boxed highlight** for one punchy word ("LYING", "unrejectable")
- Keep titles ONE line where possible; long titles break the clean top-third look
- Tool names like "Higgsfield" are too long for titles — use as logo drops in-video instead

### Title formula molds (ranked by her performance)

4. "stop [tool/behavior] from [bad thing]"

## 3 · THE PRODUCTION PIPELINE (END-TO-END)

**Flow: 30-min raw video → finished ~60–90s reel**

1. **Descript trim** — Cindy says "good take" after each good line. The owner does Ctrl+F for "good take" in the Descript transcript, reviews each, selects the best. 30 min → ~1 min. (Fast, not a bottleneck.)
2. **Screen recordings** — via **OpenScreen** (free alternative to Screen Studio/Focusee). Was the #1 time sink (~2 hrs) before the Build Sheet system. Manual zoom/pan in OpenScreen is slow — RULE: do zooms in EITHER OpenScreen OR CapCut, never both. Prefer CapCut keyframe-zoom.
3. **CapCut assembly** — import Descripted video + screen recordings, then the Personality Layer.
4. **Personality Layer** — text layers (3 fonts), memes/GIFs, and SFX. RULE: no animation appears on screen without a paired SFX.
5. **Auto-captions** — CapCut auto-caption, Poppins, word-by-word animation, bottom third, never covering her mic.
6. **Color correction + face retouching** — standard grade + skin smoothing.
7. **Upload to CapCut Teams.**

### The Build Sheet system (core workflow innovation)
For every new script, Claude generates a **Build Sheet** (docx) with these sections:
1. **Pre-Recording Checklist** (v2.0 addition) — every tab/login/prompt ready before recording; kills mid-capture re-records
2. **Title options** — 4–6 ranked, in her format, accent word marked
3. **Recording Session Plan** — ALL captures batched into ONE OpenScreen sitting, numbered R1/R2/R3…, with type, what to capture, raw length, edit note
4. **Shot List** — every script line mapped: TH (talking head) or Rec#, with timestamps from the Descript transcript
5. **Personality Layer Map** — text beats (font specified per beat), meme moments flagged, locked timecode SFX table using REAL file names
6. **CapCut Template notes** — duplicate-and-fill workflow

### The 6 screen-recording types (every capture falls into one)
1. **The Setup** — opening Claude, picking model (Opus/Sonnet/Haiku), new chat
2. **The Prompt Reveal** — typing/pasting the prompt, hitting send (the money shot; type first word manually, paste the rest)
3. **The Generation** — Claude streaming (speed-ramp 3–4× in edit)
4. **The Result** — finished output (slow scroll; zoom the key line)
5. **The Connect/Setup flow** — wiring Claude to a tool, step-by-step clicks
6. **The Proof/Payoff** — final artifact in its real home

Decision rule: a script line needs a recording ONLY if it references something happening on screen.

### Recording best practices
- Fresh browser window, bookmarks hidden (Ctrl+Shift+B), all other tabs closed, notifications muted
- Browser zoom **110–125%** so text survives the 9:16 crop
- Capture browser WINDOW only, not full screen; cursor capture ON, click-highlight ON
- Move cursor slowly/deliberately; pause ~1 sec before each click (zoom anchors)
- Prompts pre-copied to clipboard; sample inputs baked into prompts so Claude never asks follow-ups mid-recording (no back-and-forth to edit out)
- If a result renders messy/long: regenerate, or add "Keep the entire response under 120 words"
